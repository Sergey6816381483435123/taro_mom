# Сайт на 20 языках

Редакция `product-20261110`: 240 страниц — по 12 на каждом языке из `locales.json`. URL заданы в `routes.json`, тексты в `content/<code>.json`. Существующие адреса сохранены; `/en/` — только redirect, `/en/<topic>/` — самостоятельные английские страницы. Бренд «Тарошенька» только в RU, «Tarot» в остальных версиях. Арабский/персидский — RTL. Переключатель языка открывает ту же тему.

Генерация и проверка из чистого checkout требуют только Python 3.10+:

```sh
python3 sitegen/generate.py
python3 sitegen/generate.py --check
python3 sitegen/validate.py
python3 -m http.server 8765 --bind 127.0.0.1
```

Браузерная проверка требует Playwright и Chromium. Она посещает только локальный HTTP сервер; отчёт и снимки сохраняются вне репозитория:

```sh
python3 sitegen/browser_check.py --base http://127.0.0.1:8765 --output /tmp/taro-site-qa
```

Пилот оформления Натальной карты и Гороскопов подключается только для RU/EN: `visual-themes.json`, `assets/astro-themes.css`, `images/en/astro-*.svg`. Для его браузерной проверки добавь `--locales en,ru --pages natal,horoscopes`; остальные 236 HTML должны оставаться прежними.

Кнопки направлений в шапке RU/EN оформляет `assets/navigation-buttons.css`, подключённый ко всем 24 страницам этих языков. Исходный вид одинаков; подсветка — hover и focus-visible. Остальные языки используют прежнюю навигацию.

Генератор обновляет все 240 HTML и соответствующие записи sitemap. Семь прежних общих файлов и redirect защищены `legacy-integrity.json`. Он не вводит сборщик или runtime-зависимость: GitHub Pages публикует готовые файлы. Не запускать старый игнорируемый `tools/generate_site.py` для новой редакции: он рассчитан на прежнюю схему контента.

Три входа в `generate.py` должны совпадать с действующим master и проверенным реестром URL. Браузерный `?ref=` требует Taro schema105 и backend r75 или совместимого преемника. Основной бот и Астро сохраняют `start=ref974025936`; Астро сначала открывает чат, затем приложение кнопкой. Клик не означает регистрацию или получение бонуса.

`images/en/app-*.webp` — снимки настоящего опубликованного интерфейса r76 с полностью подменёнными демонстрационными API-данными, без реальных аккаунтов, вопросов или результатов. `product-images.json` фиксирует происхождение, размеры и хеши. Иллюстрация hero переиспользует существующий рисунок в WebP. Эти файлы не генерируются при сборке сайта.

Порядок: готовность приложения → окружение и пробная пара RU/EN → редактура и полная локальная проверка → публикация → публичная приёмка.

После исправлений повторяй затронутые проверки; общую матрицу повторяй при изменении общего шаблона, стилей или поведения.

Публикация — обычный fast-forward push собственного репозитория в `main`; CNAME сохраняется. При регрессии подготовить обратный коммит выпуска, проверить его локально и опубликовать тем же способом. Не применять force push. После Pages build проверить HTTPS, 240 страниц и точное совпадение изменённых файлов с опубликованными байтами.

Индексация, поисковые позиции, AI citations и полевые Core Web Vitals подтверждаются только внешними данными. После выпуска владелец может отправить sitemap в Search Console/Bing и проверить URL; доступ к этим сервисам не входит в сборку сайта.

Перед браузерной матрицей проверь Chromium, системные библиотеки и наличие шрифтов на одной странице каждого языка. Если существующая QA-среда доступна, используй её; временные пути `/tmp` не считаются постоянной зависимостью. Проверки сайта не отправляют запросы генерации, регистрации или оплаты в продукт.

Подробные требования к оформлению, SEO и доступности: [PLAYBOOK.md](PLAYBOOK.md). Готовность приложения и live-проверки: `/opt/stacks/bots/Taro/go/ops/QA_RUNBOOK.md`.

## Повторная съёмка интерфейса

`capture_product.py` требует Playwright, Chromium и Pillow. Передай проверенный frontend-пакет опубликованного приложения и обезличенный каталог локализаций:

```sh
python3 sitegen/capture_product.py --frontend /path/to/frontend --inventory /path/to/live-inventory.json --output /tmp/taro-product-capture
```

Все сетевые обращения перехватываются; неожиданный API/хост блокируется. Реальные аккаунты не используются, генерация и платежи не вызываются. Картинки берутся только из `rider_waite_classic`; тексты примера — `content/<code>.json:demo`. Сначала проверь `--locales en,ru`, затем снимай все 60 изображений. Папка `images/en/` историческая: язык указан в имени каждого файла.

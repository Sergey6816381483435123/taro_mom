## Context

Пилот четырёх страниц RU/EN одобрен. Пользователь подтвердил все разделы и все 20 языков; текущий сайт содержит 240 страниц,12 типов. Стек статический, факты и URL сохраняются.

## Goals / Non-Goals

Единая выразительная атмосфера без потери читаемости. Новых функций, страниц, меню, способов входа и цен нет.

## Decisions

- Переиспользуем одобренные SVG; добавляем девять геометрических иллюстраций для остальных тем. Векторы дают прозрачность и малый вес без генерации растра. Изображения декоративны, текст остаётся HTML. Карты в декоре — условные орнаментальные рубашки; скриншоты приложения и Rider–Waite не меняются.
- Общий `product-themes.css` заменяет подключение пилотного CSS; прежний файл сохраняется для закешированных HTML. Тематический hero и CTA применяются везде; главная сохраняет исходную иллюстрацию. Каталоги получают небольшие превью соответствующих тем. Подробные тексты остаются на спокойном фоне.
- Отдельный реестр связывает тип страницы и SVG. Тексты трёх карточек гороскопов переводятся на 18 оставшихся языков; RU/EN сохраняются.
- Для RTL меняем сторону расположения декора и направление затемнения; сами иллюстрации не отражаем, чтобы не переворачивать символы.
- Проверяем первый EN/RU/RTL пример, затем 240 страниц. Браузерная проверка пакетная, без полноразмерных снимков каждой страницы, с сохранением промежуточного отчёта. Независимо проверяем переводы, metadata и публичные файлы.

## Risks / Trade-offs

- Декор мешает тексту → затемнение, непрозрачные кнопки, мобильный просмотр.
- Длинные переводы/RTL → текучая сетка, логические стороны, матрица 320–1440 px и увеличение.
- Дополнительные картинки → SVG до 40 КБ, одинаковые файлы для всех языков, lazy loading превью и заданные размеры.
- Общие стили влияют на 240 страниц → все страницы проходят статическую и адаптивную проверку, контроль metadata относительно исходного выпуска.

## Migration Plan

Сначала исходники и локальная генерация, затем проверка и обычный push в main. Дождаться Pages success, проверить HTTPS/байты всех публичных страниц и ресурсов, выполнить представительную публичную браузерную приёмку. Откат — обратный коммит выпуска без force push.

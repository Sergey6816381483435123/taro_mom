## Context

240 статических страниц генерируются одним шаблоном. Пользователь согласовал пилот только Натальной карты и Гороскопов RU/EN.

## Goals / Non-Goals

Добавить выразительный декор и различить три формата гороскопов. Не менять остальные страницы, продуктовые факты, навигацию, URL и входы.

## Decisions

- SVG для геометрических небесных иллюстраций: прозрачность, чёткость, небольшой вес. Растровая генерация здесь не требуется.
- Отдельный CSS подключается условно для четырёх страниц. Общие стили сохраняются; пустые новые параметры шаблона не изменяют остальные HTML.
- На мобильных декор становится фоном с затемнением; на широких экранах иллюстрация занимает правую часть hero. Текст и CTA остаются контрастными.
- Три статические карточки внутри существующей страницы Гороскопов: ежедневный, личный любовный, для двоих. Семантические заголовки и тексты доступны без JS; декоративные изображения скрыты от скринридера.

## Risks / Trade-offs

- Декор мешает тексту → затемнение, непрозрачные CTA и ручная проверка 320–1440 px.
- Общий генератор меняет другие языки → сравнение хешей 236 HTML с исходным состоянием.
- SVG замедляет отрисовку → ограниченные градиенты без анимации и тяжёлых фильтров; проверка загрузки.

## Migration Plan

Генерация → статические проверки всех страниц → браузерная матрица четырёх страниц → commit/push → Pages success → публичная проверка изменённых файлов. Откат — обратный коммит выпуска, без force push.

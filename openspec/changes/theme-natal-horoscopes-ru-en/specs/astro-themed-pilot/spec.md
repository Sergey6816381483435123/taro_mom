## ADDED Requirements

### Requirement: Тематическое оформление пилота

Сайт MUST показывать зодиакальный круг на Натальной карте RU/EN и небесные иллюстрации с сердцами на Гороскопах RU/EN. Остальные 236 HTML MUST оставаться прежними.

#### Scenario: Посещение пилотной страницы

- **GIVEN** существующая страница Натальной карты или Гороскопов RU/EN
- **WHEN** посетитель открывает её
- **THEN** тематический фон виден, текст читаем, изображения декоративны, URL и metadata сохранены.

### Requirement: Три формата гороскопов

Страница Гороскопов MUST различать ежедневный, личный любовный и любовный для двоих в видимом HTML, сохраняя факты master и прежний подробный текст.

#### Scenario: Просмотр без JavaScript

- **GIVEN** браузер без JavaScript, ширина от 320 px
- **WHEN** посетитель читает Гороскопы
- **THEN** видны три формата, все тексты и шесть входов; нет горизонтальной прокрутки.

### Requirement: Сохранение доступности и поиска

Пилот MUST сохранять canonical, hreflang, JSON-LD, disclaimer, три входа в прежнем порядке и одинаковый исходный вид кнопок. Клавиатурный фокус MUST быть виден. Новые файлы MUST работать на GitHub Pages.

#### Scenario: Проверка выпуска

- **GIVEN** опубликованные четыре страницы
- **WHEN** выполняются проверки HTTPS, ресурсов, ссылок и вёрстки
- **THEN** файлы доступны, совпадают с проверенным выпуском и работают при увеличении текста и без JS.
